# Bus Trackr

A simple bus tracking app made with React Native and Expo. Works on Android, iOS and web.

## Features

- List of bus routes with search
- Favourite routes saved on the device
- Pull to refresh
- Live bus position from the server
- Pick your stop and see when the bus arrives
- Alert when the bus is one stop away
- Switch direction of the route
- Timetable with next buses
- Map of the route
- Find the nearest bus stop
- Dark mode

## Run

```
npm install
npm run server
npm start
```

Start the server and the app in two terminals. Scan the QR code with Expo Go, or press `w` to open it on web.

If the server is not running the app still works with saved routes.
